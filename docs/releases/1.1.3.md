# TapAuth 1.1.3

TapAuth 1.1.3 hardens Raspberry Pi setup password checks and admin/registration
code comparison. Local registry, MySQL, Firebase, and NFC recognition flow are
otherwise unchanged.

## What changed

- Reject the `.env.example` MySQL password placeholder during Raspberry Pi setup.
- Compare admin/registration codes with `hmac.compare_digest` and accept `X-TapAuth-Code`.
- Synchronize application, citation, archival, and documentation version references.

## Deploy or update

For a fresh Pi, follow [getting started](../getting-started.md). For an
installed kiosk:

```bash
cd ~/TapAuth
git pull --ff-only origin main
bash scripts/update_pi_from_github.sh
sudo systemctl restart airhub.service
sudo systemctl status airhub.service
```

Back up operational data and private configuration first. After updating,
confirm the service, reader, registration, repeat recognition, and any enabled
MySQL or Firebase reconciliation path.
