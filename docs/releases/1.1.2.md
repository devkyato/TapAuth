# TapAuth 1.1.2

TapAuth 1.1.2 is a presentation and citation maintenance release. It does not
add a new kiosk feature or change the local registry, MySQL, Firebase, or NFC
runtime flow.

## What changed

- Expanded Zenodo metadata into sanitizer-safe, sectioned HTML.
- Updated creator and non-author contributor metadata without asserting a DOI,
  ORCID, or legal name.
- Expanded Citation File Format metadata and the public documentation index.
- Added a task-oriented Raspberry Pi getting-started guide.
- Clarified that TapAuth is the product even when a local checkout folder has
  another name, and that this repository is an application deployment rather
  than a published source package.

## Deploy or update

For a fresh Pi, follow [getting started](../getting-started.md). For an
installed kiosk:

```bash
cd ~/TapAuth
git pull --ff-only origin main
bash scripts/update_pi_from_github.sh
sudo systemctl restart airhub.service
sudo systemctl status airhub.service
```

Back up operational data and private configuration first. After updating,
confirm the service, reader, registration, repeat recognition, and any enabled
MySQL or Firebase reconciliation path.
